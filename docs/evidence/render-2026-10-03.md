# Render evidence — 2026-10-03

## Scope

This increment is limited to the D3D11 renderer and VTF software decoder. It does not claim complete Source material rendering, model rendering, lighting, water, particles, or native-quality parity.

## Changes

- `native/src/native_renderer.cpp`
  - World vertex shader now forwards the mesh normal through `NORMAL0`; the pixel shader no longer consumes an uninitialized interpolator.
  - Shader compile failures preserve the HRESULT in `Renderer::lastError()`.
- `native/src/vtf_texture.cpp`
  - Added bounded RGBA conversion for VTF formats 1, 2, 3, 4, 5, 6, 8, 9, 10, 11, 16 and 17.
  - Existing DXT and RGBA paths remain intact.

## Verification

- `git diff --check`: passed for the task changes.
- `cmake --build native/build --config Release --parallel 2`: passed.
- `native/build/Release/tf2_demo_native.exe` remained alive for 3 seconds in a launch smoke test; it was then stopped by the test harness.

## Limits

- VTF palette-indexed format 7 is still unsupported because a palette resource reader is not present.
- VTF cubemap faces, mip selection, bumpmap reconstruction and VMT shader semantics are not yet connected to the D3D11 pipeline.
- Device removal is reported through `lastError()` but automatic device/resource recreation is not implemented in this isolated change.
