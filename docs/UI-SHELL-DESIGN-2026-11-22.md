# 界面外壳设计 · C 打底 + A 全屏（2026-11-22 23:57 定）

两种状态，同一个窗口：
- **窗口模式（C）**：标准 Windows 程序——菜单栏、工具栏、画面、进度条、状态栏，右侧可收起的玩家面板。
- **全屏模式（A）**：画面铺满显示器，比分、小地图、击杀信息、视角玩家的血量和充能叠在画面上；进度条和播放按钮在鼠标移动时出现，静止 2 秒淡出。

## 3. 全屏模式叠加层

| 元素 | 位置（1080p） | 数据来源 | 何时显示 |
|---|---|---|---|
| 比分 + 回合时间 | 顶部居中 | 队伍分数 / 回合计时器实体（**属性名待用快照确认**） | 一直 |
| 小地图 | 右上 180×180 | 已有 `--hud-minimap` | 一直（M 切换） |
| 击杀信息 | 小地图下方，最多 5 条，6 秒消失 | `player_death` + userinfo 名字 | 一直 |
| 视角玩家读数 | 左下：大号血量、兵种和武器；医生显示 UBER 条 | `playback_hud.cpp` | 镜头在玩家体内时 |
| 跟随提示 | 右下，镜头模式切换上方 | 跟随状态 | 一直 |
| 播放条 | 底部 96px：进度条（Uber / 击杀标记）、5 个按钮、时间、速度 | D3D 自绘，点击在窗口过程判定 | 鼠标移动后出现，静止 2 秒淡出；暂停时常驻 |

- 进入：F11、Alt+Enter、工具栏"全屏"、视图菜单。退出：F11、Alt+Enter、Esc。（I2 2026-11-23：F11 进；Alt+Enter 保留作别名。）
- Alt+Enter 走 `WM_SYSKEYDOWN`（现在窗口过程不处理它，交给 DefWindowProc 会响一声）。DXGI 默认也会抢 Alt+Enter 去切独占全屏：代码里没有调用 `MakeWindowAssociation`，所以要加 `DXGI_MWA_NO_ALT_ENTER`，全屏一律走无边框窗口，不用独占模式（不改显示模式、Alt+Tab 不黑屏）。
- 双击画面进全屏：现在窗口类没有 `CS_DBLCLKS`，加上会把第二次单击变成 `WM_LBUTTONDBLCLK`，可能影响已有的拖动和点击处理，所以只在 `--ui-shell on` 下加。
- Esc 现在没有绑定任何动作，全屏时用它退出不冲突。
- H 键在两种模式下都是"隐藏全部叠加层"，只剩画面（截图、录屏用）。
- 淡出用 HUD 那一遍的 alpha，200 ms 线性；`--capture-frame` 截帧时叠加层状态固定为"显示"，保证截帧可复现。

## 5. 界面语言（2026-11-23 定：中文）

- 菜单、工具提示、状态栏、对话框、玩家面板表头：**中文**。
- 所有界面字符串放进一张表 `native/src/ui_strings.cpp`（`uiText(UiTextId)` 返回 `const wchar_t*`），代码里不散写字面量；以后加英文只加一列，按 `ui.ini` 的 `[ui] language=` 选。
- 源文件已是 `/utf-8` 编译（`tf2-libraries.cmake`），中文字面量写成 `L"…"` 即可；菜单和状态栏都是 Unicode 控件（`CreateWindowExW`、`AppendMenuW`），不需要额外字体。
- **trace、命令行开关、按键名、ini 键名保持英文不变**：门禁读的是这些，翻译它们等于改契约。状态栏里显示的 tick 等字段也从同一份数据来，只是标签中文化。
- 全屏叠加层（D3D 里画的）受 8×8 位图字体限制，仍只用英文和数字（`UBER 100%`、`FOLLOW`）。

### 8.1 对局统计（离线，整场最终数据）

**每个玩家一行**（按队分组）：兵种（按上场时间排序的图标）、K / A / D、KA/D、K/D、伤害 DA、DA/分钟、承受伤害 DT、受治疗 HR、爆头、背刺、占点、拦截占点、拿药包次数。
**医生块**：治疗量、Uber 次数（按医疗枪种类分）、掉 Uber（`medic_death` 带 charged）、平均充能时间（由 Uber 开始时刻和上一次 Uber 结束/复活时刻推算）。
**队伍合计**：K、DA、Uber、掉 Uber、占点；**回合**：每回合胜方、用时、占点顺序。
**暂不做**：空中命中（airshot）。`player_hurt` 不带"受害者是否在空中"，要用受害者那一刻的 `m_fFlags`，而现在的实体历史太稀疏，做不准。宁可不显示，也不显示错的数。

**来源和校验**：统计是纯函数（事件表 + userinfo + 兵种时间线 → 表格），不依赖显卡。
- 探针 `demo_open_probe --scan --match-stats` 打印同一张表。
- 门禁拿 t64 的事件 oracle（`evidence/t64-events/oracle/`）独立重算 K/D/伤害/治疗，两边逐项相等。
- 如果有对应的 logs.tf 页面，再对一遍（logs.tf 来自服务器日志，伤害口径可能有个位数差，只作参考）。

**界面**：按住 Tab 显示（同 TF2 记分板的习惯），松开消失；L 键常驻打开/关闭。全屏和窗口模式都能用，用 F0 的字体画。

## 9. 启动窗口 → 分析 → 工作区（2026-11-23 定）

参考 wombo14/tf2-demo-analyser（GPL-3.0，Rust）的流程，只借思路，不搬代码：先分析，再从结果点进播放器；点一条就跳到前 3 秒，并切到那个人的视角。

### 9.1 启动窗口（约 940×640）
- 拖入或打开 .dem；“最近打开”读 `ui.ini` 的 `recentDemo0..7`。分析结果按文件 sha256 缓存，同一个文件不用再分析。
- 分析阶段：读头 → 解析数据包 → 完整性（task-35 文件层：tick 单调、序号、服务器时钟偏移、header 记账）→ 卡顿 / 瞬移 / 急转。
- 结果：完整性一行；异常列表每条显示“起 → 止 tick、持续 tick 数、时间、类型、相关玩家”。点任意一条 → 打开工作区，跳到起点前 3 秒（200 tick）播放；瞬移和急转还会切到那个人的第一人称。

### 9.2 工作区（原“窗口模式”改名）
- 画面里只保留顶部比分和队名；去掉左下角的血量 / Uber 框、小地图和提示文字。准星保留。
- 鼠标：点一下画面只接管鼠标、不切人。接管后和全屏一样：空格切第一 / 第三人称，双击切自由视角；左键 / 右键切下一个 / 上一个玩家。
  Esc 在全屏时退出全屏，在窗口模式下释放鼠标。F11 进入或退出全屏；原来 F11 的“重置视角”改到 Home，Alt+Enter 保留作全屏的别名。
  失去焦点时自动释放鼠标。复查模式下先按 Esc 退出复查。
- 右侧面板的医生行（2026-11-23 用户要求）：血量照常显示，后面多一格 Uber：充能百分比加本场已开次数（Ü 64% ×3），行底多一条 3 px 的充能条；开 Uber 期间这一格变白，显示剩余秒数并随之缩短；死亡时充能清零、格子变灰。数据：充能取 CWeaponMedigun.m_flChargeLevel；已开次数是截至当前 tick 的 m_bChargeRelease 上升沿（P4 fx 普查已经在读，bagel 全场 12 次）；剩余时间从上升沿开始按 8 秒倒数，读到 m_bChargeRelease 回落就结束。Kritz / 快速治疗 / 疫苗按 P4 的物品号显示 K / Q / V。

- 底部从上到下：
  1. **视角转速曲线**：画当前跟随的人每 tick 视角转了多少度，急转在曲线上是又高又窄的尖峰；有阈值线，超过的部分标红。只在跟随某人时显示。
  2. **时间轴**：每局一段底色，上沿是胜方颜色的色条，进行中的局用灰色；击杀刻度，RED 的击杀画在中线上方、BLU 的画在下方；
     跟随某人时只显示他的击杀（上方）和死亡（下方）；书签是橙色三角。
  3. **在场条**（只在跟随某人时显示）：绿 = 录像里他活着，灰 = 录像里他死了，空 = 这段录像里没有他的数据

  5. **逐 tick 条**：把选中异常前后各 20 tick 一格一格摊开，异常的 tick 标红；点一格就暂停在那个 tick。
