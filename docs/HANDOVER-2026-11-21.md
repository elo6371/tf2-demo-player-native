## 1 项目是什么

**一句话**：一个不依赖 Source 引擎的 TF2 demo 回放器 —— 自己解析 `.dem`（网络包 + 快照 + 实体表），自己用 D3D11 画 BSP 世界、实体模型、第一人称 viewmodel、天空与 HUD，用 Win32 开窗口，把"看录像"做到**精确到 tick、可抓帧、可门禁化**。

- 技术栈：C++17 / Win32 / Direct3D 11；构建 MSVC + CMake(nmake)，产物在 `native/build-nmake/`。
- 产物：产品 `native/build-nmake/tf2_demo_native.exe`，诊断探针 `demo_open_probe.exe`、`native_ui_probe.exe` 等，以及根目录 **142 个门禁脚本**（`.sh`/`.py`），证据存档 `evidence/`。
- 不做什么：不是引擎、不跑服务器、不承诺逐像素还原 Source 引擎；导出（剪映/MF）未开始；CI 只覆盖 tier 1。

## 2 构建、运行、门禁

```bash
# 所有构建/抓帧都走 hostlock，避免与其他 worktree 抢设备
bash tools/lockrun.sh lead -- bash build-target.sh tf2_demo_native demo_open_probe
# 产物
native/build-nmake/tf2_demo_native.exe
native/build-nmake/demo_open_probe.exe

# 一次抓帧（pr600，tick 600）
native/build-nmake/tf2_demo_native.exe --demo <demo.dem> --capture-tick 600 \
  --capture-frame out.bmp --audio-disabled --hidden-window
```

必须知道的构建规矩：

1. **新增源文件先 `git add` 再构建**：build-identity 戳读的是 git index，未入库文件会让身份门禁对不上。
2. **编辑过的源文件先 `touch`**：nmake 依赖 mtime，某些编辑工具不改 mtime 会导致旧 obj。
3. `/W4` 零告警 + 七个目标 `/WX`，告警即失败；不要靠抑制告警过关。
4. 门禁入口：`verify-fast.sh`（短）、`verify-all.sh`（全量）、单脚本（如 `hud-check.sh`、`minimap-check.sh`）；证据写 `evidence/`（入库）或 `.scratch/`（不入库）。
5. 常用样本：`E:/demo测试/cp_process_f12/STV/…matcha…cp_process_f12.dem`（pr600）、`D:/TF2_Demo_Player/testdata/demos/…cp_snakewater_final1.dem`、`E:/demo测试/pl_upward_f12/POV/autorecord_2026-08-08_21-43-59.dem`。TF 根：`D:/SteamLibrary/steamapps/common/Team Fortress 2/tf`（按机器不同，抓帧脚本里都显式传）。

### 7.1 基础光照：实体/武器环境光 + Half-Lambert（卡 task-36/37/38）

**先更正前提**：世界 baked lightmap **不是缺口**。它已按 ColorRGBExp32 解析（`native/src/bsp_map.cpp:263`）、只吃 `styles[0]`（`:966` 的 `hasLightmap`）、装 shelf 图集（`:833-881` 选宽、`:1077-1104` 打包，可超过历史 2048）、逐三角形写 lightmap UV（`:1151-1152`），掉面单独计数（`:1652`）。世界 PS 真的采样并乘进 albedo（`native/src/native_renderer_shaders.cpp:436-453`，`pow(1/2.2)` 后 `albedo *= lightColour`）。N21 的地图灯也已接：`light_environment` 解析在 `native/src/bsp_map.cpp:654-657`、结构 `native/include/bsp_map.h:153-165`、世界 PS 的 sun/ambient/16 盏灯在 `native/src/native_renderer_shaders.cpp:531-590`。开关 `--world-lightmap on|off` 默认 on（`native/src/main.cpp:4267-4271`）。

**真缺口**：
1. 实体/道具 PS `modelPixelSource`（`native/src/native_renderer_shaders.cpp:720-728`）写死方向光：`diffuse = saturate(dot(normal, normalize(float3(0.35,0.55,0.75)))); lighting = 0.62 + 0.38 * diffuse`，没有地图太阳、没有 ambient cube、不是 Half-Lambert，连 cbuffer 都没有。
2. 第一人称武器 PS（`:1146-1176`）另写死 `(-0.30,0.42,0.86)`、`0.55 + 0.45 * diffuse`。
3. 全树没有 `LUMP_LEAF_AMBIENT_INDEX(52)` / `LUMP_LEAF_AMBIENT_LIGHTING(56)` 解析。
4. 世界图集三个尾巴：HDR-only 地图退 `AverageIntensity`（`native/src/bsp_map.cpp:1640-1644`，判定在 `:272-273` 要求 HDR 与 LDR 等长）、面片紧贴打包无 1px clamp border、掉面只有计数没有清单。

**Step 1（task-36，S–M）**：实体/武器 6 向 ambient cube + Half-Lambert。
- 新常量块 `ModelLightingConstants` 绑 PS `b1`（与 VS 骨骼 b1 不冲突）：`float4 ambientCube[6]`、`sunDirectionAndIntensity`、`lightingParams`（x=开关）。
- 两个 PS 各加 `lightingParams.x > 0.5` 分支：`f = saturate(dot(N,L)*0.5+0.5); diffuse = f*f;` 立方体权重按 N² 与三轴正负；**关闭时算术一字不改**。
- 常量由 `native_renderer_frame.cpp` 从 `worldLights_` 推：`+Z`≈sky（sun*0.6+ambient）、`-Z`≈ground（ambient*0.6）、`±X/±Y`≈ambient*0.8+sun*0.25；无地图灯时用暖天冷地常量；6 色与开关进 trace。
- CLI 按 `--world-lightmap` 的既有 `wcscmp` 写法加 `--lighting off|basic`，默认 off。
- 先加只读 trace 自证实体法线在世界空间（骨骼矩阵是否含实体旋转），不对就先修。
- 验收：off 的 pr600 tick 600 抓帧 md5 = `2ddade35`；basic 同 tick 人物/武器背光不死黑、侧光连续，给 1:1 局部裁图与像素读数；`/W4` 零告警。

## 9 坑与规矩（交接必读）

1. **hostlock**：所有构建/抓帧串行走 `bash tools/lockrun.sh <owner> -- <cmd>`，否则多 worktree 抢设备会互相污染证据。
2. **build-identity**：新增源文件必须先 `git add`；`touch` 编辑过的源文件；否则身份门禁和增量构建都会骗你。
3. **`/W4` 零告警 + 七个目标 `/WX`**：告警即失败，别用 pragma 压。
4. **pin 绑定 exe 身份**：任何 BMP md5 pin 必须同时给抓帧装置（demo/tick/编译身份），跨提交的旧 pin 不能直接当门槛（task-9 之后 `9681f12c`→`d9544cd6`→`2ddade35` 就是三段身份）。
5. **取证不要用假源码**：参考库规则见 `docs/REFERENCE-REPOS-2026-11-21.md`，外部代码一行都不许复制，结论必须写"库+路径+文件+行号 → 本仓文件:行号"。
6. **`evidence/` 是入库存档**：`evidence/hud` 曾被其它 worktree（`t82-pvs`/`t51-hud`）的脚本覆盖，本轮已还原到 HEAD；以后在别的 worktree 跑 HUD 门禁要设输出目录。
7. **`.scratch/` 不入库**：报告引用它时必须给复现命令。`analysis/world-cull-oracle/*.png`（3.1 MB）是 task-9 的 oracle 图，未被文档引用，暂未入库。
8. **demo 协议**：该样本 `demoProtocol=3`，76 字节包信息后是 int32 inSequence、int32 outSequence、int32 length；篡改工具按这个布局写（`.scratch/n35-tamper/tamper.py`）。
9. **音频**：本机默认设备是错的，门禁一律 `AUDIO_DEVICE=6`；听感从未验收。
10. **HUD/overview 历史断言不跨 exe 身份**：231 断言那批是历史 exe 的读数，不能直接转移到当前 exe。
