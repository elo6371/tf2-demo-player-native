# Evidence: what is here, what is not, and how to get to it

## The rule this tree follows

`main` carries only the evidence the chain **reads at run time**. Everything else -- 98.5%
of the old repository -- is on `archive/full-history-2026-11-13` and in the all-refs
bundle. Nothing was deleted; the large evidence was moved off the default branch so that a
clone is usable.

|---|---|---|
| `evidence/` in the source commit `2f8d78d` | 6,172 | 1,001,288,795 (954.9 MB) |
| `evidence/` in `main` | 37 | (the two frozen baselines below) |
| everything else in `main` | 492 | |

## The 37 files that must stay

**`evidence/probe-baseline/` -- 11 files.** Recorded probe output that step 7
("probe output is additive") diffs the current probes against. Names:
`added-lines`, `ashville73`, `asset-refs-pre-world-model`, `bagel`, `comp`, `decal`,
`protocol23`, `saytext2`, `short2024`, `small`, `snakewater` (`.txt`). If one is missing,
the step cannot tell whether a probe gained a field or lost one.

**`evidence/corpus-calib/` -- 26 files.**

| File | What it is |
|---|---|
| `demos.txt` | the **pinned list of 24 demo files** the calibration step is required to cover |
| `corpus-summary.json` | the measured census of those 24 (numbers below) |
| `reports/*.txt` (24) | the frozen per-demo baseline that step 9 compares a mutated copy against |

`.gitignore` explains why the reports are force-included, and it is worth quoting because
deleting them looks harmless:

> `verify-all.sh` step 9 compares a mutated copy against these 24 reports as a frozen
> baseline ... ignoring them lets a fresh clone have the pinned 24 names but no reports,
> so step 9 reads `pinned_reports=0` and fails 48 assertions.

So: do not delete `evidence/probe-baseline/` or `evidence/corpus-calib/`, do not let a
`git clean -xdf` near them, and do not "tidy" the `.gitignore` negation that re-includes
them.

## How to read one old evidence file without cloning 955 MB

```bash
# from the archive branch, if the host allows partial clones
git clone --filter=blob:none --sparse git@github.com:elo6371/tf2-demo-player-native.git
cd tf2-demo-player-native
git sparse-checkout set --no-cone /evidence/t93-playback/
git checkout archive/full-history-2026-11-13

# or one file at a time, with no checkout at all
git show archive/full-history-2026-11-13:evidence/t93-playback/<file>
```

```bash
# or from the offline bundle, which needs no network
git clone archive/tf2-native-all-refs-2026-11-13.bundle tf2-offline
```

The bundle is 241,243,698 bytes and contains **every** ref the old repository had: 142
local branches, 55 remote heads, the tag, and the source commit. Its sha256 is in
`docs/HANDOFF-MISSING.md` next to the file name, because the file itself is too large to
commit.

## How new evidence should be recorded

1. Gates write raw output under `evidence/verify/` (`verify-all.sh:234`); the fast tier
   writes `evidence/fast/`. Both are gitignored except the two frozen baselines.
2. A claim that matters goes into a document with the commit, the gate, and the verdict
   line copied literally.
3. A binary under test is identified by `build-identity-content.sh hash` plus the exe's
   own `--version`, never by date.
