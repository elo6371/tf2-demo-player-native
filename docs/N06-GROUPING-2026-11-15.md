### 3.2 白噪族（W）判据 D-W

### E-A 白噪：bagel 的 ssbump 面（唯一 resolved < declared 的面）

**H-A**：bagel 的白噪（纯白底+黑点型，white240 16.5%）由 `WINTER/BLENDGRAVELTOGRASS_BAGEL` 的 ssbump 贴图缺失引起——该材质是**七图里唯一 ssbump 解析不全的**：`feature=ssbump declared=17 visible=15 resolved=11 missing=6 first=WINTER/BLENDGRAVELTOGRASS_BAGEL resource=Metal/wall011d_bump-ssbump`（其余六图 ssbump missing=0）。当前基线里 `feature-apply` 行七图**全是 0**（bump/detail 都没生效）。

```bash

"$EXE" "${COMMON[@]}" --demo "$DEMO" --world-bump off --capture-frame "$OUT/bagel_bumpoff.bmp" 2> "$OUT/bagel_bumpoff.trace"
"$EXE" "${COMMON[@]}" --demo "$DEMO" --world-bump on  --capture-frame "$OUT/bagel_bumpon.bmp"  2> "$OUT/bagel_bumpon.trace"
```

**第 0 步是复现闸**：`bagel_bumpoff.bmp` 的 sha256 前 8 必须是 `81a40435`（= S5）。对不上，基线不成立，先查 `--capture-tick`/相机，别往下走。

**预期（H-A 成立时）**：
- trace：`feature=ssbump` 的 `resolved` 由 11/17 升到 17/17（declared=17、missing 由 6 降到 0）；若 bump 通路随之接通，`feature-apply` 从 `applied=0` 变成非 0。
- 像素：`hf60%` 8.765 → **<=1.8**（落进非 W 区间）；`white240%` 16.516 → **<1.0**；最密噪块 (768,32) 的 hf_pairs 598 → **<100**。

**负控（H-A 错时看到什么）**：
- 若两帧 sha 相同 → 开关没接通（先证开关，不是证明假设）；
- 若两帧不同但 `hf60%` 变化 <5% 相对 → **缺 ssbump 不是主因**，转 UV/filter 分支：同机位再加 `--world-uv on`、`--world-texel on` 各一帧，看噪点是否随 UV 走；
- 若 bump on 后噪**更糟** → 是采样/filter，不是缺贴图。

**资源/时长**：每帧一次产品启动；G2 实测七图 13 min（≈2 min/图，trace 12–29 MB），本实验 2 帧 ≈ 4–6 min，读 trace 10 min。需 GPU 与独占运行权（hostlock 归执行者，本文件不碰）。

### E-C 浅蓝面：sunshine 的等厚斜带（厚度 44 px、斜率 −0.20）

**H-C（本文件最强的机制假设）**：这条带是**水面被当成普通世界几何画了出来**。依据都在同一份 trace 里：
- `cp_sunshine.trace:164` → `gpu: world water-upload state=unavailable faces=0 triangles=0 warpPlanned=0 textureBound=1 textureSource=shipped-water-colour texture=water/water_hydro_base … waterMap=-11008.0,128.0,-288.0..-256.0,10368.0,120.0 … reason=water draw disabled by the caller`——water pass 被**调用方关闭**，只绑了一张 shipped-water-colour 单色贴图；
- 同一 trace 的 `gpu: world geometry` 行报 `waterTriangles=410`（七图最多：sunshine 410 / gullywash 354 / upward 170 / bagel 118 / sultry 8 / process 0 / product 0）；
- 每图 `gpu: world geometry=all blend=on`。

→ 410 个水面三角形被装配了，但没走 water pass，而是留在普通世界几何里，用单色贴图 → **恒定色平面**。这正好解释 D-P 的近恒定色 + 等厚 + 有直线边。

```bash
DEMO=$(ls "$TFROOT"/../demos/*cp_sunshine*.dem | head -1)        # N11 §1.2: SUNSHINE.dem
"$EXE" "${COMMON[@]}" --demo "$DEMO" --world-water off --capture-frame "$OUT/sun_wateroff.bmp" 2> "$OUT/sun_wateroff.trace"
"$EXE" "${COMMON[@]}" --demo "$DEMO" --world-water on  --capture-frame "$OUT/sun_wateron.bmp"  2> "$OUT/sun_wateron.trace"
```

复现闸：`sun_wateroff.bmp` sha 前 8 必须是 `65a74ccc`（= S4）。

**预期（H-C 成立时）**：
- trace：`water-upload` 的 `state` 不再 `unavailable`（或 `reason` 不再是 `water draw disabled by the caller`）；`water` 状态行 `draws >= 1`、`triangles=410`；出现 warp/reflection 相关行。
- 像素：`(140,180,204)±6` 的像素数 49,441 → **<1,000**；低场浅蓝 3.05% → **≈0**；带子要么消失，要么变成有波纹/反射的水面。

**负控**：
- 两帧 sha 相同 → `--world-water` 没接到渲染路径（先查 `main.cpp` 里 `worldWaterRequested` 的消费点，这是 E-C 的第一步，不是最后一步）；
- trace 变了但带子还在 → 带子**不是 water pass 画的**，弃 H-C，转 H-C2（世界几何里有面用了 water 材质 → 单色贴图），用 `--world-face-trace-points` 在带内打 3 点（如 600,480 / 700,450 / 800,420）看材质名；
- 带子变黑 → water pass 存在但缺光照/反射，**仍然是水面**（对 D39 是「水面被渲染成平面」的证据，不是否证）。

**资源/时长**：2 帧 ≈ 4–6 min。
