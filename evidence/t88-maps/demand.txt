WHY THIS FILE EXISTS
  main.cpp's kWorldTriangleCapacity was 200,000 because that was the BSP
  parser's DEFAULT, not because anyone measured a map. This file is the
  measurement, taken before the capacity was chosen, so the constant in
  main.cpp:4280 is a number with a reason rather than a round figure.

    geometry budget capacity=200000 requested=242361 dropped=42643 facesDropped=3513 brushFacesDropped=3246 brushModelsDropped=86 firstFace=12204 firstBrush=worldspawn state=truncated
  cp_snakewater_final1 at --triangle-limit 100000:
    geometry budget capacity=100000 requested=242361 dropped=144209 facesDropped=4296 brushFacesDropped=3246 brushModelsDropped=86 firstFace=11421 firstBrush=worldspawn state=truncated

  Two facts this pair establishes:
    * requested is 242,361 at 200,000 and at 100,000 and at 4,000,000. The
      demand is a property of the map; only "dropped" moves with the capacity.
    * dropped is never SMALLER than the shortfall (42,361 at 200,000) and can be
      larger: a displacement grid the budget refuses is replaced by a fallback
      fan whose triangles occupy slots too, so 42,643 were refused to fit
      200,000. world-geometry-budget-check.sh asserts the inequality for that
      reason.

WHY 400,000 AND NOT 250,000
  250,000 would cover today's four maps with 3 % headroom, which is not headroom:
  it would turn the next map change into a silent truncation again, and the
  trace line would report it after the fact. 400,000 keeps the worst authorised
  map at 61 % of the buffer, stays far below the 4M the probe already runs in
  the same memory, and is a bound rather than a guess -- the assertion that
  requested <= capacity runs on every map in the gate.

COST OF RAISING IT
  Nothing preallocates triangleLimit entries: native/src/bsp_map.cpp builds
  map.triangles with push_back (line 148-201 reserve other vectors, never this
  one), so the buffer's peak follows the triangles a map actually produces, not
  the limit. Raising the limit therefore adds only the triangles the map really
  draws -- on snakewater 42,361 of them -- instead of reserving 400,000 up
  front. The measured build and capture timings are in MAP-BUDGET-FIX.md.
